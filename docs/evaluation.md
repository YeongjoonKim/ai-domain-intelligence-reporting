# Evaluation

12 behavioral tests exercise the sample contracts. Five repository-quality tests
exercise the scanner, not model performance. Run `python3 -m unittest discover -s tests -v`.

No live collection, scheduler, LLM, admin settings service or forecast exists. A zero baseline has undefined percent change. The projection guard checks exact structured insight objects, not free-form prose.

Future evaluation needs independently labeled tasks and separated baselines.
A synthetic regression pass rate is not a real-world quality score.
