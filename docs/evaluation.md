# Evaluation

25개 공개 테스트는 입력 검증·단위·기준시점·0 기준값·충돌·정형 projection, 실행 JSON/HTML과 저장소 검사기, 운영 집계의 공개 필드 계약·선택 범위·화면 근거를 포함합니다. 실제 수집·LLM 문장·예측 성능은 평가하지 않았습니다.

합성 fixture의 +12 points / +15% 등은 Decimal 산술과 projection을 재계산한 결과입니다.
운영 리포트의 시장 변화나 실제 사업 성과 수치와 구분합니다.

2026-10-02 별도로 실행한 기존 private reporting 회귀는 243개 통과·2개 실패였습니다.
[실제 조회량과 미해결 계약](data-to-report.md)을 공개 합성 예제의 검증 결과와 구분합니다.

후속 연구는 독립적인 task label과 baseline을 분리해야 합니다. 합성 회귀 통과율을 현장 성능으로 해석하지 않습니다.
